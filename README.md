# دفتر مدرّس العربية

تطبيق ويب لمدرّس اللغة العربية للصف الرابع الإعدادي (المنهج العراقي، الطبعة الخامسة ١٤٤٧هـ / ٢٠٢٥م).

## الأقسام
- **اليوم**: حصص اليوم، الدروس القادمة، تقدّم المنهج، والطلاب الذين يحتاجون متابعة.
- **المنهج**: وحدات الجزأين ودروسها، وحالة كل درس، والخطة الفصلية الموزعة على الأسابيع.
- **دفتر التحضير**: تحضير يومي بقوالب جاهزة لكل نوع درس، وتنزيله ملف Word.
- **الطلاب والحضور**: الشعب، تسجيل الحضور، ورسائل الغياب لأولياء الأمور.
- **الدرجات**: الاختبارات والنسب والتقديرات والترتيب، والتصدير إلى Excel.
- **الاختبارات**: بنك أسئلة بإجابات نموذجية، وبناء ورقة اختبار، ونموذج (ب)، ونموذج الإجابة.
- **أدوات الصف**: قرعة عشوائية، مؤقت، تقسيم مجموعات، ونقاط مشاركة.
- **التقارير**: سجل الحضور الشهري وتقرير كل طالب.
- **مرجع القواعد**: بطاقات قواعد قابلة للإضافة والتعديل.

## الحفظ
تُحفظ البيانات في متصفح الجهاز. استخدم «الإعدادات والنسخ الاحتياطي» لتنزيل نسخة احتياطية.
